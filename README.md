# CALGB40603_PrePost_Analyses
CALGB 40603 was a phase II clinical trial that evaluated the effects of adding carboplatin or bevacizumab to a NACT regimen of weekly paclitaxel, followed by dose-dense doxorubicin and cyclophosphamide, in patients with stage II/III TNBC. Here we provide code for Rädler et al., JCI, 2026 (PMID:42550611, DOI: 10.1172/JCI205962)
